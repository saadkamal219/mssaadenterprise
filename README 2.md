# মেসার্স সাদ এন্টারপ্রাইজ—ওয়েবসাইট

## চালানোর নিয়ম
`index.html` ব্রাউজারে খুলুন। কোনো ব্যাকএন্ড বা ইনস্টলেশন লাগে না। (বাংলা ফন্ট লোড হতে ইন্টারনেট লাগবে।)

## ফাইল কাঠামো
`*.html` পেজ · `css/style.css`, `css/responsive.css` · `js/script.js` (সাধারণ কাজ ও কনফিগ), `js/form.js` (ফর্ম) · `images/` (ছবি, লোগো, ফেভিকন)

## ছবি পরিবর্তন
`images/` ফোল্ডারের `.svg` প্লেসহোল্ডার একই নামে `.jpg` ছবি দিয়ে বদলান এবং HTML-এ `src`-এর এক্সটেনশন `.jpg` করুন। ছবি ১৫০ KB-এর নিচে (WebP/JPG) রাখুন। বাস্তব প্রকল্পের ছবি দিলে "নমুনা ডিজাইন" ট্যাগ মুছে দিন।

## লোগো পরিবর্তন
বর্তমান লোগো একটি ইনলাইন SVG (সব HTML-এর `.brand`-এর ভেতরে এবং `images/favicon.svg`)। আসল লোগো থাকলে `images/logo.png` রেখে ওই SVG-র জায়গায় `<img src="images/logo.png" alt="লোগো" height="44">` বসান।

## যোগাযোগের তথ্য ও হোয়াটসঅ্যাপ
`js/script.js`-এর প্রথম লাইনের `CONFIG` পূরণ করুন (`whatsapp: "8801XXXXXXXXX"`, `phone`, `email`, `facebook`)। এটি সব পেজের ফোন, ইমেইল, ফেসবুক ও হোয়াটসঅ্যাপ লিংক এবং ফর্ম একসঙ্গে আপডেট করে। `whatsapp` ফাঁকা থাকলে ফর্ম কিছু পাঠায় না, শুধু ত্রুটির বার্তা দেখায়।
## গুগল ম্যাপ
`contact.html`-এ `id="map"` ব্লকে গুগল ম্যাপের embed `<iframe>` বসান।
## ভবিষ্যতে ব্যাকএন্ড
`js/form.js`-এর শেষে `window.open(...)`-এর জায়গায় `fetch()` দিয়ে আপনার সার্ভারে পাঠান।
## প্রকাশ
**GitHub Pages:** রিপোজিটরিতে ফাইল আপলোড → Settings → Pages → Branch `main` / root। **Cloudflare Pages:** Git সংযুক্ত করুন বা ফোল্ডার আপলোড করুন; build command ফাঁকা, output directory `/`। ডোমেইন পেলে প্রতিটি পেজের canonical লাইনের মন্তব্য খুলে ঠিকানা বসান।
